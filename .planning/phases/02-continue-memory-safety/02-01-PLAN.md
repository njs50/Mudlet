**Step 4 — Update callers that call `.value(key)` and dereference the result:**

`QMap::value()` returns by value (copies the unique_ptr) and will not compile. Each call site must switch to a find-based pattern. The raw pointer is still valid as long as the map entry lives, so callers can safely use `.get()` or the raw pointer.

For each site, the pattern is:
```cpp
// OLD
SomeType* ptr = map.value(key);   // or map.value(key)->method()

// NEW (read-only access)
auto it = map.constFind(key);
if (it != map.constEnd()) {
    SomeType* ptr = it->get();   // or it->get()->method() or (*it)->method()
}
```

Apply to each file:
