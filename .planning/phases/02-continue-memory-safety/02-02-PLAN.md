  <action>
**Part A — mpHandlers migration:**

1. In `src/discord.h`:
   - Add `#include <memory>` if not already present
   - Change `DiscordEventHandlers* mpHandlers = nullptr;` to `std::unique_ptr<DiscordEventHandlers> mpHandlers;`

2. In `src/discord.cpp` constructor (`Discord::Discord()`):
   - Change `mpHandlers = new DiscordEventHandlers;` to `mpHandlers = std::make_unique<DiscordEventHandlers>();`
   - Change `memset(mpHandlers, 0, sizeof(DiscordEventHandlers));` to `memset(mpHandlers.get(), 0, sizeof(DiscordEventHandlers));`
   - `mpHandlers->ready = handleDiscordReady;` and similar `mpHandlers->` lines do NOT need changes (unique_ptr provides operator->)

3. In `src/discord.cpp` destructor (`Discord::~Discord()`):
   - Remove `delete mpHandlers;` line — unique_ptr handles it

4. Search all of discord.cpp for any other place `mpHandlers` is passed as a raw pointer to a C function (e.g., `Discord_Initialize(..., mpHandlers, ...)`). Change each to `mpHandlers.get()`.

**Part B — mPresencePtrs migration:**

5. In `src/discord.h`:
   - Change `QMap<QString, localDiscordPresence*> mPresencePtrs;` to `QMap<QString, std::unique_ptr<localDiscordPresence>> mPresencePtrs;`

6. In `src/discord.cpp` destructor or `resetData()`:
   - Find the manual `QMutableMapIterator<QString, localDiscordPresence*>` loop that deletes each value
   - Replace the ENTIRE loop with `mPresencePtrs.clear();` — unique_ptrs auto-destruct

7. In `src/discord.cpp`, find all insertion sites where `new localDiscordPresence` is created:
   - Change `auto* pTempPresence = new localDiscordPresence; mPresencePtrs.insert(key, pTempPresence);` to `mPresencePtrs.insert(key, std::make_unique<localDiscordPresence>());`
   - If code needs to use the pointer after insertion, use `mPresencePtrs[key].get()` or `mPresencePtrs.find(key).value().get()`

8. In `src/discord.cpp`, find all `mPresencePtrs.value(...)` calls. `QMap::value()` returns by value and will NOT compile with unique_ptr. Replace each with the find() pattern:
   ```cpp
   auto it = mPresencePtrs.find(applicationID);
   localDiscordPresence* pDiscordPresence = (it != mPresencePtrs.end()) ? it.value().get() : nullptr;
   ```
   Pay special attention to the `mPresencePtrs.value(nullptr)` / null-key pattern — use `mPresencePtrs.find(QString())` instead.

9. Search for any remaining `delete` of `localDiscordPresence*` in discord.cpp — remove them all.

10. Run clang-format: `$(brew --prefix llvm)/bin/clang-format -i src/discord.h src/discord.cpp`
