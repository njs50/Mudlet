**NOTE on dblsqd::Feed constructor:** The actual constructor signature in `3rdparty/dblsqd/dblsqd/feed.h` is:
```cpp
Feed(QString baseUrl = "", QString channel = "release", QString os = QString(), QString arch = QString(), QString type = QString());
```
It does NOT accept a `QObject* parent` parameter and inherits from `QObject` but has no parent-based construction. Therefore, Qt parent-child cannot be used. Use `std::unique_ptr<dblsqd::Feed>` instead.

1. In `src/updater.h`:
   - Add `#include <memory>` if not already present
   - Change `dblsqd::Feed* feed;` to `std::unique_ptr<dblsqd::Feed> feed;`

2. In `src/updater.cpp` constructor:
   - Change `feed = new dblsqd::Feed();` to `feed = std::make_unique<dblsqd::Feed>();`
   - The subsequent `feed->setUrl(baseUrl, channel, QString(), arch, QString());` does NOT need changes (unique_ptr provides operator->)

3. In `src/updater.cpp` destructor:
   - Remove `delete(feed);` or `delete feed;` line — unique_ptr handles it

4. In `src/updater.cpp`, find all places where `feed` is passed as a raw pointer to functions (especially `dblsqd::UpdateDialog(feed, ...)` calls). Change each to `feed.get()`:
   - `new dblsqd::UpdateDialog(feed, ...)` becomes `new dblsqd::UpdateDialog(feed.get(), ...)`
   - There are multiple UpdateDialog construction sites in updater.cpp — update ALL of them

5. In `src/updater.cpp`, find all signal/slot connections that use `feed` as sender/receiver object. `connect(feed, ...)` must become `connect(feed.get(), ...)`:
   - `KDToolBox::connectSingleShot(feed, &dblsqd::Feed::ready, ...)` becomes `KDToolBox::connectSingleShot(feed.get(), &dblsqd::Feed::ready, ...)`
   - `KDToolBox::connectSingleShot(feed, &dblsqd::Feed::loadError, ...)` becomes `KDToolBox::connectSingleShot(feed.get(), &dblsqd::Feed::loadError, ...)`
   - `connect(feed, &dblsqd::Feed::ready, ...)` becomes `connect(feed.get(), &dblsqd::Feed::ready, ...)`
   - `connect(feed, &dblsqd::Feed::downloadFinished, ...)` becomes `connect(feed.get(), &dblsqd::Feed::downloadFinished, ...)`
   - **IMPORTANT:** Check for any `connect(feed, &dblsqd::Feed::ready, feed, [=, this]() {...})` patterns where `feed` also appears as the receiver context — change BOTH occurrences: `connect(feed.get(), &dblsqd::Feed::ready, feed.get(), [=, this]() {...})`

6. All `feed->someMethod()` calls (e.g., `feed->load()`, `feed->getUpdates(...)`, `feed->getReleases()`, `feed->isReady()`, `feed->downloadRelease(...)`, `feed->getDownloadFile()`, `feed->getUrl()`) do NOT need changes — unique_ptr provides operator->.

7. Run clang-format: `$(brew --prefix llvm)/bin/clang-format -i src/updater.h src/updater.cpp`
