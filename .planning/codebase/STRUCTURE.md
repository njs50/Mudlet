# Structure

## Top-Level Layout

```
Mudlet/
├── src/                    # Main application C++ source
│   ├── mudlet-lua/         # Lua standard library shipped with Mudlet
│   │   ├── lua/            # Lua source files (geyser UI framework, utilities)
│   │   └── tests/          # Busted unit tests for Lua API
│   ├── ui/                 # Qt Designer .ui files
│   ├── 3d-models/          # 3D assets for map view
│   └── CMakeLists.txt      # Build config for src/
├── test/                   # C++ unit tests (Qt Test framework)
├── 3rdparty/               # Vendored external libraries
│   ├── edbee-lib/          # Code editor widget
│   ├── lcf/                # Lua compatibility fix
│   ├── qtkeychain/         # Secure credential storage
│   ├── sentry-native/      # Crash reporting (Sentry)
│   ├── dblsqd/             # Auto-updater
│   └── sparkle-glue/       # macOS Sparkle updater bridge
├── translations/           # Qt .ts/.qm i18n files
├── cmake/                  # CMake helper modules
├── CI/                     # CI helper scripts
├── docker/                 # Docker build environments
├── docs/                   # Developer documentation
└── .github/
    ├── workflows/          # GitHub Actions CI/CD
    └── CONTRIBUTING.md     # Coding standards
```

## Naming Conventions

### Classes
- Main domain classes: `T` prefix + PascalCase — `TTrigger`, `TAlias`, `TTimer`, `TConsole`, `TMap`
- Engine/unit containers: `PascalCase` + `Unit` suffix — `TriggerUnit`, `AliasUnit`, `TimerUnit`
- Dialog classes: `dlg` prefix + PascalCase — `dlgTriggerEditor`, `dlgProfilePreferences`
- Application class: lowercase `mudlet`

### Files
- Each class in its own `.h`/`.cpp` pair matching the class name
- `TLuaInterpreter` split into domain files: `TLuaInterpreter{Domain}.cpp`
- Qt Designer files: `src/ui/{feature_name}.ui` (snake_case)

### Members & Variables
- Member variables: `m` prefix + camelCase — `mProfileName`, `mpHost` (pointer), `mIsConnected`
- Signals/slots: camelCase — `profileChanged()`, `slot_connectionEstablished()`
- Slots use `slot_` prefix convention in some classes

### Build Artifacts
- Profile data saved to: `~/.config/mudlet/profiles/{profileName}/`
- Application config: `~/.config/mudlet/`
